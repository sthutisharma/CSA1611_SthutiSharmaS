# DWDM Practical Programs

This repository contains the **Data Warehousing and Data Mining (DWDM)** practical programs completed as part of the college laboratory course.

The practicals are implemented using **R programming** and cover basic concepts of data preprocessing, data analysis, statistics, and data mining.

## 📚 Topics Covered

* Data Preprocessing
* Data Cleaning
* Data Transformation
* Data Normalization
* Data Visualization
* Statistical Analysis
* Correlation Analysis
* Data Binning and Smoothing
* Classification and other Data Mining techniques

## 🛠️ Technology Used

* **R Programming**
* RStudio

## 🎯 Objective

The objective of these practicals is to understand and implement fundamental **Data Warehousing and Data Mining concepts** using R.

## 📝 Note

This repository is maintained for **academic and college practical purposes**.
